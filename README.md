\# Прогнозування відтоку клієнтів телекомунікаційної компанії



\## Опис проєкту



Це навчальний проєкт з Data Science, метою якого є прогнозування відтоку клієнтів телекомунікаційної компанії.



Модель оцінює ймовірність того, що клієнт припинить користуватися послугами компанії, та допомагає визначити клієнтів із підвищеним ризиком відтоку.



Проєкт охоплює аналіз даних, їхню попередню обробку, навчання та оцінювання моделі машинного навчання, створення вебзастосунку й запуск застосунку в Docker-контейнері.



\## Мета проєкту



\- Провести дослідницький аналіз даних.

\- Підготувати дані для машинного навчання.

\- Побудувати та оцінити модель класифікації.

\- Прогнозувати ймовірність відтоку клієнтів.

\- Створити інтерактивний вебзастосунок.

\- Забезпечити запуск застосунку за допомогою Docker.



\## Набір даних



У проєкті використано файл `internet\_service\_churn.csv`.



Набір даних містить 72 274 рядки та 11 стовпців із характеристиками клієнтів і цільовою змінною `churn`.

\## Аналіз та попередня обробка даних



Для дослідницького аналізу даних використано Pandas, Matplotlib і Seaborn.



Під час підготовки даних передбачено обробку пропущених значень, підготовку ознак для моделі та стандартизацію числових даних, де це необхідно.



Етапи попередньої обробки включено до конвеєра моделі, щоб нові дані клієнтів оброблялися узгоджено з даними, використаними під час навчання.



\## Модель машинного навчання



Для прогнозування відтоку клієнтів використано модель класифікації Decision Tree (дерево рішень).



Модель навчено на історичних даних про клієнтів. Для оцінювання її якості використано тестову вибірку та метрики класифікації.



\### Результати оцінювання моделі



| Метрика | Результат |

|---|---:|

| Accuracy — точність класифікації | 93,72% |

| Precision — точність позитивних прогнозів | 95,01% |

| Recall — повнота виявлення відтоку | 93,58% |

| F1-score — гармонійне середнє Precision і Recall | 94,29% |



Ці показники характеризують роботу моделі на тестовій вибірці. Вони відрізняються від індивідуальної ймовірності відтоку, яку показує вебзастосунок для конкретного клієнта.



\## Вебзастосунок



Для взаємодії з моделлю створено вебзастосунок на основі Streamlit.



Користувач може ввести характеристики клієнта та отримати результат прогнозування.



Застосунок відображає:

\- оцінену ймовірність відтоку;

\- прогнозований статус клієнта;

\- інформацію про низький або підвищений ризик відтоку.



Прогноз є оцінкою моделі й не гарантує майбутню поведінку клієнта.

\## Інструкція із запуску через Docker



\### Необхідні компоненти



\- Встановлений і запущений Docker Desktop.

\- Файли проєкту, збережені на комп’ютері.



\### Крок 1. Відкрити папку проєкту



Відкрийте командний рядок Windows та виконайте команду:



```cmd

cd %USERPROFILE%\\Desktop\\telecom-churn-project

```



\### Крок 2. Створити Docker-образ



```cmd

docker build --no-cache -t telecom-churn-app .

```



\### Крок 3. Запустити контейнер



```cmd

docker run -d --name telecom-churn-container -p 8501:8501 telecom-churn-app

```



\### Крок 4. Відкрити вебзастосунок



У браузері перейдіть за адресою:



http://localhost:8501



Введіть характеристики клієнта та запустіть прогнозування.



\### Зупинка застосунку



Щоб зупинити контейнер:



```cmd

docker stop telecom-churn-container

```



Щоб запустити його повторно:



```cmd

docker start telecom-churn-container

```



Щоб видалити контейнер:



```cmd

docker rm -f telecom-churn-container

```

У межах навчального проєкту реалізовано основні етапи роботи з машинним навчанням: аналіз даних, попередню обробку, навчання й оцінювання моделі, а також створення вебзастосунку для прогнозування відтоку клієнтів.



Застосунок дає змогу оцінювати ризик відтоку на основі введених характеристик клієнта. Використання Docker забезпечує запуск застосунку в контейнеризованому середовищі.
